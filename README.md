# Profile_Card_03
A simple profile card made using HTML5 and CSS3.
Profile Card Using CSS Box Model

About the Project

This is my third web development assignment. I created a simple profile card using HTML and CSS.

Features

- Profile picture
- Name and introduction
- Student information
- Social media links
- Rounded corners and shadow effects
- Simple and clean design

Technologies Used

- HTML5
- CSS3

Files

- "index.html" - Contains the structure of the profile card.
- "style.css" - Contains the styling of the card.

CSS Concepts Used

- Margin
- Padding
- Border
- Border Radius
- Box Shadow
- Text Alignment

How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in your browser.

What I Learned

- Understanding the CSS Box Model.
- Using margin and padding.
- Styling a profile card.
- Adding images and links using HTML.
- Using hover effects in CSS.
